# CODSOFT Java Development Internship

This repository contains my Java Development Internship tasks completed for CodSoft.

## Task 1 - Number Game

A Java-based number guessing game where the computer generates a random number between 1 and 100 and the user tries to guess it.

### Features

- Random number generation
- User input
- Too High / Too Low feedback
- Maximum 7 attempts
- Multiple rounds
- Score calculation

### Technology Used

- Java
- Scanner
- Random

### How to Run

Compile:

```bash
javac NumberGame.java
